# Diagramas de arquitectura · Modelo C4

La arquitectura sigue el modelo **C4**, del panorama general a la estructura interna:

1. **Contexto:** personas y sistemas externos alrededor del POS.
2. **Contenedores:** navegador, API, base de datos e integración FEL.
3. **Componentes:** módulos de backend, su responsabilidad y relaciones principales.

- [Componentes del backend](c4-componentes.md)
